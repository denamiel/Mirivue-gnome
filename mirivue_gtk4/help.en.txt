Browse Files
Each pane has its own folder, sorting, search and tabs. “Two Panes” shows or hides the second pane; F3 toggles it. Ctrl+T opens a tab; Ctrl+W closes a tab, or the window if only one tab remains. Ctrl+Page Up / Down switches tabs. Alt+Home opens Home; Ctrl+D bookmarks the current folder. Ctrl+L lets you enter a location. Double-click empty space to go to the parent folder.

Views and Columns
Ctrl++ / Ctrl+- changes icon size and Ctrl+0 resets it. F5 or Ctrl+R reloads the folder. “List View” displays files as rows; “Grid View” displays icons. Click a column heading to sort, or drag it to change its order. “Columns…” lets you choose visibility and profiles. Visible columns are shared by both panes, while their order can be configured separately. Folder size first shows the number of direct items; optional total size is calculated in the background.

Media Tools
Open “Media Tools…” to inspect information, edit metadata, test playback or organize a selection. Commands apply to the active pane selection. Video bitrate is read from the media metadata; no full bitrate calculation or subjective quality score is offered. Total folder duration is in Organization. Exact duplicates are found recursively within the chosen folder.

Copying and Moving
Ctrl+C copies, Ctrl+X cuts and Ctrl+V pastes into the open folder of the active pane. Right-click one folder for “Paste Into This Folder”. The file clipboard exchanges Copy/Cut operations with GNOME Files. For name conflicts, choose to rename, skip, or explicitly replace files; existing folders are not replaced. Operations run in the background. “Operations…” shows the queue, results and errors. The Places footer shows the selection and active progress, with a discreet three-dot Operations icon and tooltip. Cancel Analyses appears beside it only during an analysis. When the sidebar folds away in a narrow window, Operations and compact progress remain visible in the header.

Preview
F9 shows or hides the preview. A checkerboard shows transparent image areas; PDFs appear on a white page. Space does the same when a file is selected in the list or grid. Right-click the player to play or pause; double-click to enter or leave fullscreen. For images, the vertical wheel zooms and the horizontal wheel moves between images. For videos and audio, the wheel changes neither volume nor playback position. In fullscreen, arrow keys navigate the selection. Audio starts at zero volume.

Places and Privacy
Folder bookmarks are shared with GNOME Files and managed from the “Bookmarks” section of the sidebar. “Favorites” lists files starred in GNOME. Files, analyses and collections stay local. F1 opens Help, Ctrl+, opens Preferences, Ctrl+? shows keyboard shortcuts, and Alt+Enter shows Properties. Preferences lets you disable recent media and operation or playback history.

Creation and Properties
The folder menu offers “Create New” for a folder or text file without replacing an existing entry. “Properties” shows general information and Unix permissions for a local item, verifying changes after they are applied. Symbolic links are not changed. Alt+Shift+F4 opens a terminal in the current folder when one is available.
