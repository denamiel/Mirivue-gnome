Browse Files
Each pane has its own folder, sorting, search and tabs. “Two Panes” shows or hides the second pane; F3 toggles it. Ctrl+T opens a tab; Ctrl+W closes a tab, or the window if only one tab remains. Ctrl+Page Up / Down switches tabs. Ctrl+Shift+T reopens the last closed tab. Tabs can be reordered or detached, and their menu can close the other tabs. A tab overview is available in narrow windows. Alt+Home opens Home; Ctrl+D bookmarks the current folder. Ctrl+L lets you enter a location. Double-click empty space to go to the parent folder.

Views and Columns
Ctrl++ / Ctrl+- changes icon size and Ctrl+0 resets it. F5 or Ctrl+R reloads the folder. “List View” displays files as rows; “Grid View” displays icons. Click a column heading to sort, or drag it to change its order. “Columns…” lets you choose visibility and profiles. Visible columns are shared by both panes, while their order can be configured separately. Folder size first shows the number of direct items; optional total size is calculated in the background.

Media Tools
Open “Media Tools…” to inspect information, edit metadata, test playback or organize a selection. Commands apply to the active pane selection. Video bitrate is read from the media metadata; no full bitrate calculation or subjective quality score is offered. Total folder duration is in Organization. Exact duplicates are found recursively within the chosen folder.

Copying and Moving
Ctrl+C copies, Ctrl+X cuts and Ctrl+V pastes into the open folder of the active pane. Right-click one folder for “Paste Into This Folder”. The file clipboard exchanges Copy/Cut operations with GNOME Files. For name conflicts, choose to rename, skip, or explicitly replace files; existing folders are not replaced. “Merge Folders” offers an explicit merge with decisions for internal conflicts. Ctrl+Z reverses a tracked local operation after verifying its items. Operations run in the background. “Operations…” shows the queue, results and errors. The Places footer shows the selection and active progress, with a discreet three-dot Operations icon and tooltip. Cancel Analyses appears beside it only during an analysis. When the sidebar folds away in a narrow window, Operations and compact progress remain visible in the header.

Preview
F9 shows or hides the preview. A checkerboard shows transparent image areas; PDFs appear on a white page. Space does the same when a file is selected in the list or grid. Right-click the player to play or pause; double-click to enter or leave fullscreen. For images, the vertical wheel zooms and the horizontal wheel moves between images. For videos and audio, the wheel changes neither volume nor playback position. In fullscreen, arrow keys navigate the selection. Audio starts at zero volume.

Places and Privacy
Folder bookmarks are shared with GNOME Files and managed from the “Bookmarks” section of the sidebar. “Favorites” lists files starred in GNOME. Files, analyses and collections stay local. F1 opens Help, Ctrl+, opens Preferences, Ctrl+? shows keyboard shortcuts, and Alt+Enter shows Properties. Preferences lets you disable recent media and operation or playback history.

Creation and Properties
The folder menu offers “Create New” for a folder, text file or document from available XDG templates without replacing an existing entry. “Properties” shows general information and Unix permissions for a local item, verifying changes after they are applied. Symbolic links are not changed. Ctrl+. opens a terminal in the current folder when one is available.

Search and Summary
Typing searches filenames, in the folder or its subfolders. Media filters are explicit. The summary describes the selection, or only the items actually displayed after filtering. The rename preview distinguishes unchanged names, planned changes and conflicts. No file changes before confirmation.

Remote Folders
GVfs folders use the same list and grid views, sorting and GNOME file clipboard. Remote filename search can descend into subfolders accessible through GVfs; access errors are reported. Creation, single-item rename and deletion depend on backend capabilities. A failed trash request never causes automatic permanent deletion. Batch renaming, analyses and media editing remain local-only. Ctrl+Shift+T reopens a closed tab in the current session. Preferences also offers optional restoration of the last closed window’s tabs at startup. Secondary tabs load their folder when activated; selections and scroll positions are not restored.

View Preferences
Remembering the view and sort order per folder is optional. Up to three captions can appear below icons. Dates use regional formatting and Mirivue’s simple/detailed choice. These preferences are not synchronized with GNOME Files.

Original Metadata Backup
When backup is enabled, the first existing version of the edited file is preserved as “.mirivue-original”. A hidden “.mirivue-backup.json” record binds this original to the version published by Mirivue. Later edits reuse the original after verification. A replaced file, modified backup or unrecognized record blocks reuse; none of these files is overwritten. Older successive backups are retained and never automatically adopted. For XMP edits, the backup covers the existing XMP sidecar, not the media.

Folder Updates
Displayed folders update automatically through GIO, including GVfs views when the backend supports monitoring. This behavior is always enabled and has no Preferences switch. F5 remains available to request a manual refresh, particularly when the server provides no change notifications.
