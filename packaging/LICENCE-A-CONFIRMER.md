# Licence de publication à confirmer

Les sources GNOME 0.6.21 reçues ne contiennent pas de licence explicite.
Cette préparation ne leur attribue aucune licence et n'accorde aucun droit nouveau.

Le marqueur `LicenseRef-Mirivue-Pending` dans les recettes est provisoire.
La publication COPR, AUR et des versions GitHub est bloquée par
`packaging/check_release.py --require-license` tant que le titulaire n'a pas
choisi la licence et que son texte n'est pas ajouté dans `LICENSE`.

La licence MIT du code original KDE ne suffit pas, à elle seule, à attribuer
une licence aux sources GNOME. Le choix doit être confirmé pour cette édition.
